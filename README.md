# 西湖清趣 · 圆相 3D

## 空间约定（2026-10-23 起）

- **当代底图：上北下南（north-up）**，宽幅覆盖西湖及杭城周边。
- **圆相**浮层：默认 **TPS 配准**（画 UV↔今 lat/lng 控制点）扭曲贴今湖；可关回示意原位。
- **星点**：默认收起仅辉光；可点开/全局「星名」展开短名。
- **双位置**：配准（morph）开 → 星钉 **今址 lat/lng**；关扭曲 → 星移到 **圆相 Freer/FLOOR_UV** 画位。gx 仅作卷上权威；缺 UV 者 gx 环估并标待定。
- 环墙长卷按跋文 gx 逆时针环湖（默认关闭，收入「试验」）。
- **示意对照，非测绘级配准。**

## 默认氛围（2026-10-24 湖雾 P0）

- 雾：白天/街道青灰米青湖雾；夜间同色相深青灰（禁太空黑）。
- 光：晨雾色温（主光暖、补光青），压对比、少高光。
- 环壁：默认仍关；材质低饱和略暗、吃雾、无自发光。
- 未做：Bloom / 体积光 / 落叶雨 / 强天空盒；水光·尘雾粒子留 P1 且默认关。

## UI 布局（2026-10-23 侧栏）

- **砍顶栏叠层**：默认中央/上半 3D 视野不被横条挡住。

### 分割对照怎么用

1. 时间轴点选历史年（如 1929 / 1964）。
2. 顶栏点 **「分割对照（示意）」**（未选年时按钮禁用）。
3. 拖屏幕中线金色手柄：左侧当代底图，右侧该年历史图；圆相可仍半透或点「圆相」关闭。
4. 回「叠合」或点「当代」即退出分割。脚注仍标明非测绘级配准。

## 今址与配准（2026-10-23 用户私聊定稿）

1. **圆相扭曲开（默认）**：星钉当代今址 lat/lng。
2. **圆相不扭曲**：星移到圆相画上正确位置（FLOOR_UV / Freer）。
3. **圆相**用控制点（画 Freer UV ↔ 今 lat/lng）做 TPS 扭曲，默认开启与今底图对齐。
4. 星视觉：收起=辉光星点；展开=短名。

- 投影：`basemap-meta.json` bbox → `MAP_SIZE` 平面（+X 东，−Z 北，与 PlaneGeometry 底图一致）。
- 开源思路：Allmaps `@allmaps/transform` thinPlateSpline、MapWarper GCP、Leaflet.DistortableImage。
- 已知名胜（断桥、保俶塔、雷峰塔、岳坟、西泠桥、苏堤、涌金门等）用可核验公开坐标；低置信今址见控制台 `LOC_UNCERTAIN`。
- 脚注仍写「示意对照，非测绘级」。
